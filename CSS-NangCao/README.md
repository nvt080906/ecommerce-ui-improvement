4. Nội dung thực hành

Exercise 7.1 – 7.4: Document Flow, Positioning và Z-Index.
Thực hành cách hiển thị, định vị và kiểm soát thứ tự chồng lớp của các phần tử.

Exercise 7.5 – 7.9: Float, Clear và Positioning.
Xây dựng bố cục bằng float, xử lý các phần tử trôi và kết hợp kỹ thuật định vị.

Exercise 7.10 – 7.13: Multi-Column Layout và Responsive Design.
Xây dựng bố cục hai cột, ba cột và điều chỉnh giao diện theo kích thước màn hình bằng media queries và viewport.

Exercise 7.14 – 7.18: Transforms, Transitions, Filters và Animations.
Thực hành các hiệu ứng biến đổi, chuyển tiếp, bộ lọc hình ảnh và chuyển động bằng CSS.

Exercise 7.19: Using Bootstrap.
Ứng dụng Bootstrap grid system và các thành phần giao diện có sẵn.
