Buổi học 5 - Advanced Front-end

1. Nội dung học tập

  • Tìm hiểu Chrome DevTools và JavaScript Console.
  • Thực hành thay đổi các thuộc tính của trò chơi Chrome Dino bằng JavaScript.
  • Tìm hiểu Responsive Web Design.
  • Sử dụng CSS Media Queries để thay đổi bố cục theo kích thước màn hình.
  • Sử dụng thẻ picture để hiển thị hình ảnh responsive.

2. Bài thực hành

Thiết kế giao diện gồm hai phần LEFT và RIGHT, sử dụng CSS Media Queries để thay đổi bố cục theo chiều rộng trình duyệt và chế độ in.

3. Kết quả học tập

Hiểu cách sử dụng JavaScript Console để kiểm tra và thay đổi hành vi chương trình, đồng thời biết cách xây dựng giao diện web thích ứng với các kích thước màn hình khác nhau.
